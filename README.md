# Задание Velog
Два приложения с использованием Qt, которые взаимодействуют друг с другом посредством протокола UDP.

Требования к приложениям:

Приложение 1: Редактор скриптов (Сlient)

1.	Реализовать интерфейс с текстовым редактором для написания и редактирования QTScript-файлов.
2.	Добавить возможность загрузки QTScript-файла в редактор.
3.	Реализовать базовый функционал сохранения и загрузки содержимого редактора.
 
Приложение 2: Исполнитель скриптов (Server)

1.	Реализовать интерфейс с кнопкой для загрузки скрипта из первого приложения через протокол UDP.
2.	Поддерживать работу приложений как на одном компьютере, так и на разных (через ввод адреса и порта).
3.	Выполнять полученный скрипт и отображать результат его выполнения.

# Сборка

Для сбоки и запуска Client запустите следующий код:

```
qmake client.pro 
make
make clean
bin/client.exe
```

Для сбоки и запуска Server запустите следующий код:

```
qmake server.pro 
make
make clean
bin/server.exe
```

# Тестирование

## Сборка и запуск

Для тестирование запсутите сборку Velog_task:

```
qmake Velog_task.pro 
make
make clean
bin/velog_test.exe
```

Откроется два окна приложения Client и Server

## Тестирование

1. в окне Client выберете кнопку `Load` и загрузите файл test.qml в папке test корневого коталога
2. в окне Server введите данные Ip адреса и Порта из Client info окна Clinte
3. Нажмите кнопку Get QML для загрузки по UPD, в текстовом редакторе отобразится данные из формы Client
4. Нажмите Start для запуска этого кода

В случае успеха отобразятся на окне сервера следующий фигуры:

1.	Один синий залитый круг.
2.	Один незалитый круг с бирюзовым контуром.
3.	Один треугольник.
4.	Один прямоугольник.
5.  Четыре линии разных цветов
